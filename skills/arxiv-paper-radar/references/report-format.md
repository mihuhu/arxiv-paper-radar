# 中文简报同步格式

下面每个 `##` 区块对应一篇论文。标题、版本和原始摘要来自 CLI 缓存，不要改写原始英文标题或摘要。中文标题可另加元数据行。此模板不含真实或伪装抓取论文。

```markdown
# 每日论文简报 · YYYY-MM-DD

## 完整原始标题

- arXiv：[原文](https://arxiv.org/abs/实际ID)
- 提交：YYYY-MM-DD；更新：YYYY-MM-DD；版本：v1
- 作者：完整作者列表
- 作者单位：逐位列出；无法核实者写待核实
- 论文单位：仅作者栏明确列出的单位；未逐作者对应时说明
- 单位来源：实际读取的 HTML/PDF 或 API 原始来源
- 方向关联：根据摘要说明关联

### 中文摘要

100–180 字，概括问题、方法和摘要所述结果，不增加未经读取的事实。

### 原始摘要

从 new_papers 中逐字保留的 abstract 内容。
```

将模板中的实际字段替换完成后保存为 `reports/YYYY-MM-DD-中文论文简报.md`，UTF-8。链接使用真正的 arXiv ID，明确版本必须位于原始摘要前。

`sync-summaries` 按标题、ID、版本与原始摘要指纹检查；改错绑定字段会拒绝。如需更正中文，修改对应报告后重新同步。报告应同时保留原始材料来源，不能删除英文摘要以凑篇幅。
